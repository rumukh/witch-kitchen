## Electron (Windows build only)

The Windows build is an Electron runtime (MIT, © Electron contributors / GitHub Inc.) which
includes Chromium and other components. Their full license texts ship next to the executable
as `LICENSE` and `LICENSES.chromium.html` (generated by Electron itself).

## Fonts

No font files are shipped. The UI uses the operating system's fonts (Segoe UI on Windows;
Noto Sans / PT Sans / system-ui elsewhere if installed).

All art and audio are original for this project and commercially usable; per-asset sources,
tools and licenses are listed in `docs/ASSET_PROVENANCE.md` (generated from

included.
